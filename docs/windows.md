# Запуск на Windows: по шагам

Инструкция для тех, кто раньше не работал с терминалом. Нужен Windows 10 или 11
и около 30 минут, большая часть — ожидание скачивания.

## Что такое PowerShell и как им пользоваться

Всё управление проектом — это короткие команды, которые вводятся в **PowerShell**
(окно для текстовых команд, встроено в Windows).

**Как открыть:** нажмите клавишу **Win** (с логотипом Windows), наберите `PowerShell`, нажмите **Enter**.
Откроется окно с тёмным фоном и строкой вида `PS C:\Users\Иван>` — сюда и вводятся команды.

**Как вводить команды из этой инструкции:**
1. Скопируйте команду из серого блока (выделите мышью, **Ctrl+C**).
2. Щёлкните в окно PowerShell и вставьте: **Ctrl+V** или правой кнопкой мыши.
3. Нажмите **Enter** и дождитесь, пока снова появится строка `PS ...>`. Это значит, что команда выполнилась.

Вводите команды по одной. Если на экране появилось много текста — это нормально,
главное, чтобы среди него не было слов `error` или `ошибка` красным цветом.

## Шаг 1. Установить три программы (один раз)

Откройте PowerShell и выполните по очереди три команды. Каждая скачивает и ставит программу.
Если Windows спросит «Разрешить этому приложению вносить изменения?» — нажмите **Да**.

```powershell
winget install --id Git.Git -e
```

```powershell
winget install --id astral-sh.uv -e
```

```powershell
winget install --id Docker.DockerDesktop -e
```

- **Git** — скачивает код проекта с GitHub.
- **uv** — ставит Python и все библиотеки проекта.
- **Docker Desktop** — запускает базу данных.

> Если PowerShell пишет `winget не распознано как имя командлета`, установите программы вручную
> с сайтов: [Git](https://git-scm.com/download/win), [uv](https://docs.astral.sh/uv/getting-started/installation/),
> [Docker Desktop](https://www.docker.com/products/docker-desktop/). В установщиках везде жмите «Далее».

**После установки перезагрузите компьютер.** Docker это нужно обязательно.

## Шаг 2. Запустить Docker Desktop

1. Нажмите **Win**, наберите `Docker Desktop`, нажмите **Enter**.
2. При первом запуске:
   - примите лицензию (**Accept**);
   - если предложит войти в аккаунт — нажмите **Skip** или **Continue without signing in**;
   - если попросит установить или обновить **WSL** — соглашайтесь и, если попросит, перезагрузитесь ещё раз.
3. Дождитесь, пока в левом нижнем углу окна Docker появится зелёная надпись **Engine running**.

Docker Desktop должен быть запущен всегда, когда вы работаете с проектом.
Окно можно свернуть — он продолжит работать (иконка кита возле часов).

## Шаг 3. Проверить, что всё установилось

Закройте старое окно PowerShell и откройте новое (иначе оно не увидит новые программы). Выполните:

```powershell
git --version
uv --version
docker --version
```

Каждая команда должна напечатать номер версии, например `git version 2.47.0.windows.1`.
Если какая-то пишет «не распознано» — эта программа не установилась, повторите для неё шаг 1.

## Шаг 4. Скачать проект

Перейдите в папку «Документы» и скачайте туда проект:

```powershell
cd ~\Documents
```

```powershell
git clone https://github.com/krayzienike-web/mediaresearch.git
```

> Если откроется окно входа в GitHub — войдите в аккаунт, у которого есть доступ к репозиторию.

Перейдите в папку проекта:

```powershell
cd mediaresearch
```

Теперь строка выглядит так: `PS C:\Users\Иван\Documents\mediaresearch>`.
**Все дальнейшие команды выполняются именно отсюда.** Проект лежит в
«Документы → mediaresearch», его видно и в обычном Проводнике.

## Шаг 5. Создать файл настроек

Скопируйте файл-пример:

```powershell
copy .env.example .env
```

Сгенерируйте секретный ключ (он нужен для обезличивания авторов постов):

```powershell
uv run --no-project python -c "import secrets; print(secrets.token_hex(32))"
```

Появится длинная строка из цифр и букв, например `3f9a1c...e07b`. Выделите её мышью и скопируйте (**Ctrl+C**).

Откройте настройки в Блокноте:

```powershell
notepad .env
```

Найдите строку `AUTHOR_HASH_SALT=change-me`, сотрите `change-me` и вставьте свою строку.
Должно получиться `AUTHOR_HASH_SALT=3f9a1c...e07b` без пробелов. Сохраните (**Ctrl+S**) и закройте Блокнот.

## Шаг 6. Запустить базу данных

Убедитесь, что Docker Desktop запущен (шаг 2), и выполните:

```powershell
docker compose up -d
```

В первый раз скачается образ базы (~100 МБ). В конце должна появиться строка `Container mediaresearch-postgres-1  Started`.
В окне Docker Desktop во вкладке **Containers** появится `mediaresearch` с зелёным значком.

## Шаг 7. Установить библиотеки проекта

```powershell
uv sync
```

Это самый долгий шаг: скачивается Python и библиотеки, включая модель для тональности (~300–400 МБ).
Подождите, пока снова появится строка `PS ...>`.

## Шаг 8. Создать таблицы в базе

```powershell
uv run mr init-db
```

Должно напечатать: **Схема БД актуальна**.

## Шаг 9. Вписать свои бренды

```powershell
notepad config\brands.yaml
```

В файле два примера — Сбер и Магнит. Замените их на свои бренды по тому же образцу:

```yaml
brands:
  - slug: mybrand            # короткое имя латиницей, без пробелов
    name: Мой Бренд          # как показывать в интерфейсе
    search:                  # что искать в Google Новостях и поиске ВК
      - Мой Бренд
    match:
      include:               # по каким словам считаем, что это про нас
        - мой бренд
      exclude:               # что точно не про нас (можно не заполнять)
        - мой бренд кофе
```

**Важно:** отступы делаются **пробелами**, не клавишей Tab, и должны быть ровно как в примере.
Слова пишутся в любой форме: «Сбербанк» найдёт и «Сбербанка», и «Сбербанку».

Сохраните (**Ctrl+S**) и закройте Блокнот. Для первого запуска можно ничего не менять
и посмотреть, как сервис работает на примерах.

## Шаг 10. Собрать упоминания

```powershell
uv run mr collect
```

Сервис пройдёт по Google Новостям, лентам СМИ и Telegram-каналам. В первый раз ещё скачается
модель тональности (~50 МБ). В конце будет примерно так:

```
google_news: просмотрено 312, с брендами 287, новых упоминаний 290 (14.2 с)
rss: просмотрено 640, с брендами 12, новых упоминаний 12 (6.1 с)
telegram: просмотрено 118, с брендами 9, новых упоминаний 9 (3.4 с)
тональность: оценено 311 (8.7 с)
```

Жёлтые строки `WARNING ... 404` — не страшно: значит, у какого-то издания сменился адрес ленты.

## Шаг 11. Открыть интерфейс

```powershell
uv run mr web
```

Появится надпись `Откройте http://localhost:8000`. Откройте браузер (Chrome, Edge, Яндекс)
и перейдите по адресу **http://localhost:8000**.

- **Лента** — все найденные упоминания. Под каждым кнопки: «Негатив / Нейтрально / Позитив» —
  поправить, если модель ошиблась; «Мусор» — скрыть, если это не про вас.
- **Дашборд** — графики и сводка за 30 дней.

**Пока интерфейс открыт, окно PowerShell закрывать нельзя.** Чтобы остановить —
щёлкните в окно PowerShell и нажмите **Ctrl+C**.

## Как запускать в следующие разы

Установка больше не нужна. Каждый раз:

1. Запустите **Docker Desktop**, дождитесь **Engine running**.
2. Откройте **PowerShell** и перейдите в проект:
   ```powershell
   cd ~\Documents\mediaresearch
   docker compose up -d
   ```
3. Соберите свежие упоминания и откройте интерфейс:
   ```powershell
   uv run mr collect
   uv run mr web
   ```
4. Откройте **http://localhost:8000**.

### Автоматический сбор весь день

Откройте **два** окна PowerShell, в обоих сначала `cd ~\Documents\mediaresearch`.

В первом — сбор каждые 15 минут:

```powershell
uv run mr collect --every 15
```

Во втором — интерфейс:

```powershell
uv run mr web
```

Пока оба окна открыты и компьютер не спит, новые упоминания появляются сами — просто обновляйте страницу в браузере.

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| `... не распознано как имя командлета` | Программа не установлена или PowerShell открыт до установки. Закройте PowerShell, откройте заново. Не помогло — повторите шаг 1 |
| Docker Desktop пишет про **virtualization** или **WSL** | Нужно включить виртуализацию в BIOS. На рабочем ноутбуке — попросите IT. На домашнем: найдите в интернете «включить виртуализацию BIOS» + модель ноутбука |
| `error during connect` или `Cannot connect to the Docker daemon` | Docker Desktop не запущен или ещё запускается. Дождитесь **Engine running** |
| `connection refused` / `could not connect` при `mr ...` | Не запущена база: `docker compose up -d` |
| `port is already allocated` | На компьютере уже есть другой PostgreSQL. Напишите мне — поменяем порт |
| `fatal: not a git repository` или `No such file` | Вы не в папке проекта. Выполните `cd ~\Documents\mediaresearch` |
| `address already in use` при `mr web` | Интерфейс уже запущен в другом окне, или порт занят. Запустите на другом: `uv run mr web --port 8080` и откройте http://localhost:8080 |
| Ошибка при скачивании модели (`huggingface`) | Корпоративная сеть блокирует сайт. Запустите `uv run mr collect` один раз из дома — модель сохранится |
| Ошибка при чтении `brands.yaml` | Проверьте отступы: только пробелы, ровно как в примере. Пришлите мне файл — подскажу |
| Сбор прошёл, а в ленте пусто | Выполните `uv run mr stats`. Если нули — проверьте правила `include` в `brands.yaml` |

**Если застряли — скопируйте весь текст из окна PowerShell (выделить мышью → Ctrl+C) и пришлите мне.** Разберёмся.
