# Токены ВКонтакте

Нужны два токена:

| Токен | Для чего | Переменная |
|---|---|---|
| Сервисный ключ приложения | `wall.get`: стены сообществ | `VK_SERVICE_TOKEN` |
| Пользовательский токен | `newsfeed.search`: поиск по всем открытым постам | `VK_USER_TOKEN` |

> Процедуру создания приложений ВК недавно переводили на VK ID, интерфейс мог измениться.
> Если шаги ниже не совпадают с тем, что вы видите, — пройдём вместе.

## 1. Технический аккаунт

Заведите отдельный аккаунт ВК под мониторинг, не используйте личный.
Если токен заблокируют или он утечёт, личный аккаунт не пострадает.

## 2. Приложение и сервисный ключ

1. Откройте [dev.vk.com](https://dev.vk.com) → «Мои приложения» → создать приложение.
   Если отправит в кабинет VK ID для бизнеса, создайте приложение там.
2. В настройках приложения скопируйте **сервисный ключ доступа** → `VK_SERVICE_TOKEN` в `.env`.
3. Запомните **ID приложения**: он нужен для шага 3.

Этого уже достаточно, чтобы читать стены сообществ: впишите их в `config/sources.yaml`
(`vk.communities`) и поставьте `vk.enabled: true`.

## 3. Пользовательский токен (для поиска)

Классический способ (Implicit Flow) — откройте в браузере под техническим аккаунтом:

```
https://oauth.vk.com/authorize?client_id=<ID_ПРИЛОЖЕНИЯ>&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=offline&response_type=token&v=5.199
```

После подтверждения в адресной строке будет `#access_token=...` — это значение в `VK_USER_TOKEN`.
`offline` делает токен бессрочным.

Если этот способ для нового приложения не работает, нужен вход через VK ID
(авторизация с PKCE). Сделаем отдельную команду `mr vk-login`.

## Проверка

```bash
uv run mr collect --only vk -v
```

## Что держать в голове

- Лимит — около 3 запросов в секунду на токен, сборщик выдерживает паузы сам.
- `newsfeed.search` отдаёт ограниченное число результатов на запрос и, вероятно,
  имеет суточный лимит. Реальные значения замерим на этапе 1.
- Токен — пароль от аккаунта. Только в `.env`, никогда в git.
