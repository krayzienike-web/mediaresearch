# План проекта

## Цель

Внутренний сервис мониторинга упоминаний ~20 брендов одной компании в СМИ и соцсетях.
Главная ценность для PR-службы — быстро узнавать о негативе и видеть картину по брендам.

## Ключевая идея архитектуры: два способа сбора

| | СМИ, Telegram-каналы | ВКонтакте, Google News |
|---|---|---|
| Модель | Читаем все публикации известных источников, бренды ищем сами | Источник ищет по запросам бренда (`search` в brands.yaml) |
| Фильтр | `match` в brands.yaml | Тот же `match`: поиск источников неточный |

Центральная сущность — бренд с его поисковыми строками и правилами сопоставления.

## Поток данных

```
сборщик → RawDocument → pipeline: сопоставление с брендами → обезличивание → Postgres
                                   (документы без брендов не сохраняем)
```

## Этапы

### 0. Каркас ✅
Сборщики Google News, RSS, Telegram (веб-превью), ВК (newsfeed.search, wall.get);
морфологическое сопоставление; хранение без ПДн; CLI.

### 1. Проверка на живых данных
- Запустить сбор на реальных брендах, оценить объёмы и количество мусора.
- Получить токены ВК, измерить лимиты `newsfeed.search` (сколько результатов и запросов в сутки).
- Неделю вести эталон упоминаний 2–3 брендов вручную → оценить полноту и точность.

### 2. Аналитика
- Тональность: готовая модель для русского языка (rubert-tiny2 / RuBERT-sentiment), CPU.
- Кластеры перепечаток (SimHash/MinHash поверх `content_hash`).
- Комментарии ВК к постам из отслеживаемых сообществ.

### 3. Telegram-бот
- Алерты: негатив, всплеск упоминаний, публикация в крупном источнике.
- Ежедневная сводка по брендам.

### 4. Веб-интерфейс
- Лента с фильтрами, ручная правка тональности и пометка мусора.
- Графики динамики, топ источников, выгрузка в Excel.
- Ручная разметка → датасет для дообучения тональности.

### 5. Расширение
- Telegram через MTProto (история, комментарии), OK, Дзен, YouTube, Rutube.
- LLM-сводки «что произошло за день».

## Метрики качества MVP

- Задержка от публикации до появления в базе: < 15 минут.
- Полнота относительно эталона: ≥ 80%.
- Точность (доля релевантных упоминаний): ≥ 85%.

## Бюджет

Разработка — 0 ₽ (локально). Круглосуточная работа — VPS в РФ (2–4 vCPU, 4–8 ГБ RAM),
ориентировочно 1–3 тыс. ₽/мес. Источники и модели бесплатные.

## Открытые вопросы и риски

- Лимиты и условия коммерческого использования API ВК; доступ к Streaming API.
- Комментарии ВК не ищутся поиском — только с постов в отслеживаемых сообществах.
- Google News отдаёт ссылки-редиректы, а не прямые адреса статей.
- Юридическое согласование обработки (см. ADR 0001) до запуска в работу.
