# Запуск с нуля: пошаговая инструкция

> На Windows удобнее [отдельная инструкция с каждым кликом](windows.md).

Займёт 15–30 минут, большая часть — скачивание. Команды ниже набираются в терминале:
на macOS — «Терминал», на Windows — PowerShell, на Linux — любой.

## 1. Установить инструменты (один раз)

Нужно три программы: **Git** (скачать код), **Docker** (база данных) и **uv** (Python и библиотеки).
Python отдельно ставить не нужно: uv скачает нужную версию сам.

### macOS

1. Git: выполните `git --version`. Если его нет, macOS сама предложит установить Command Line Tools — соглашайтесь.
2. Docker: скачайте и установите [Docker Desktop](https://www.docker.com/products/docker-desktop/), запустите его. Он должен работать (иконка кита в строке меню) каждый раз, когда вы работаете с проектом.
3. uv:
   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```
   Закройте и снова откройте терминал.

### Windows

1. Git: установите [Git for Windows](https://git-scm.com/download/win) с настройками по умолчанию.
2. Docker: установите [Docker Desktop](https://www.docker.com/products/docker-desktop/). Он попросит включить WSL 2 — соглашайтесь и перезагрузите компьютер. Запустите Docker Desktop.
3. uv — в PowerShell:
   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```
   Закройте и снова откройте PowerShell.

### Linux

```bash
sudo apt install git            # или аналог для вашего дистрибутива
# Docker: https://docs.docker.com/engine/install/ + пакет docker-compose-plugin
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### Проверка

```bash
git --version
docker --version
docker compose version
uv --version
```

Все четыре команды должны напечатать версии без ошибок.

## 2. Скачать проект

```bash
git clone https://github.com/krayzienike-web/mediaresearch.git
cd mediaresearch
```

Все дальнейшие команды выполняются из папки `mediaresearch`.

## 3. Настроить `.env`

Скопируйте пример настроек:

```bash
cp .env.example .env            # macOS / Linux
copy .env.example .env          # Windows
```

Сгенерируйте секретную соль для обезличивания авторов:

```bash
uv run --no-project python -c "import secrets; print(secrets.token_hex(32))"
```

Откройте `.env` в любом текстовом редакторе и вставьте результат в строку `AUTHOR_HASH_SALT=`.
Больше её не меняйте. Остальное пока можно не трогать.

## 4. Запустить базу данных

```bash
docker compose up -d
```

Проверка: `docker compose ps` — у `postgres` статус `running (healthy)`.
База живёт в Docker и переживает перезагрузку компьютера: после перезагрузки
достаточно запустить Docker Desktop и снова выполнить `docker compose up -d`.

## 5. Установить зависимости

```bash
uv sync
```

Первый раз это долго: скачивается PyTorch для модели тональности
(на macOS и Windows ~200–400 МБ, на Linux ~3 ГБ — там по умолчанию ставится версия с поддержкой видеокарт).
Если тональность пока не нужна: `uv sync --no-group ml` — поставится за минуту.

## 6. Создать таблицы

```bash
uv run mr init-db
```

Должно напечатать «Схема БД актуальна». Эту же команду нужно выполнять после каждого
обновления кода (`git pull`): она применяет новые миграции и не трогает данные.

## 7. Указать свои бренды

Откройте `config/brands.yaml` и замените примеры (Сбер, Магнит) на свои бренды.
Синтаксис описан в начале файла. Каналы и ленты СМИ — в `config/sources.yaml`.

## 8. Первый сбор

```bash
uv run mr collect
```

Что увидите:

```
google_news: просмотрено 312, с брендами 287, новых упоминаний 290 (14.2 с)
rss: просмотрено 640, с брендами 12, новых упоминаний 12 (6.1 с)
telegram: просмотрено 118, с брендами 9, новых упоминаний 9 (3.4 с)
тональность: оценено 311 (8.7 с)
```

При первом запуске тональности скачается модель (~50 МБ) — это одноразово.
Предупреждения вида `RSS Ведомости: 404` значат, что у издания сменился адрес ленты: поправьте его в `config/sources.yaml` или удалите строку.

## 9. Открыть интерфейс

```bash
uv run mr web
```

Откройте в браузере **http://localhost:8000**. Остановить — `Ctrl+C`.

- **Лента** — все упоминания с фильтрами. Под каждым — кнопки тональности (если модель ошиблась, поправьте: ручная оценка больше не перезаписывается) и «Мусор» (скрыть нерелевантное). «Выгрузить в Excel» выгружает то, что сейчас отфильтровано.
- **Дашборд** — за последние 30 дней: сколько упоминаний, доля негатива, динамика по дням, бренды и главные источники. Цифры кликабельны и ведут в ленту с нужным фильтром.

## Ежедневная работа

Нужно два окна терминала, в обоих — папка проекта:

```bash
# окно 1: сбор каждые 15 минут
uv run mr collect --every 15

# окно 2: интерфейс
uv run mr web
```

Пока окна открыты и компьютер не спит, упоминания появляются сами.
Круглосуточно это будет работать, когда перенесём на сервер (следующие этапы).

## Полезные команды

| Команда | Что делает |
|---|---|
| `uv run mr collect --only telegram` | Собрать только из одного источника (`google_news`, `rss`, `telegram`, `vk`) |
| `uv run mr collect --no-sentiment` | Собрать без оценки тональности |
| `uv run mr sentiment` | Оценить тональность всего, что ещё не оценено |
| `uv run mr mentions --brand sber` | Последние упоминания в терминале |
| `uv run mr stats` | Сводка по брендам и источникам |
| `uv run mr purge` | Стереть тексты постов физлиц старше срока хранения |
| `uv run mr --help` | Список всех команд |

## Обновление кода

```bash
git pull
uv sync
uv run mr init-db
```

## Если что-то не работает

| Ошибка | Что делать |
|---|---|
| `connection refused` / `could not connect to server` | Не запущена база. Запустите Docker Desktop и `docker compose up -d` |
| `port is already allocated` при `docker compose up` | Порт 5432 занят другим PostgreSQL. В `docker-compose.yml` замените `127.0.0.1:5432:5432` на `127.0.0.1:5433:5432`, а в `.env` в `DATABASE_URL` — `localhost:5432` на `localhost:5433` |
| `password authentication failed` | Вы меняли пароль в `docker-compose.yml` после первого запуска. Проще всего пересоздать базу: `docker compose down -v` (**удалит все данные**) и `docker compose up -d` |
| `Модель тональности не установлена` | Выполните `uv sync` (без `--no-group ml`) |
| Ошибка при скачивании модели | Нужен доступ к huggingface.co. Если он закрыт в корпоративной сети, запустите один раз из другой сети: модель сохранится в кэш |
| `address already in use` при `mr web` | Порт 8000 занят: `uv run mr web --port 8080` |
| В ленте пусто после сбора | Проверьте `uv run mr stats`. Если 0 — посмотрите вывод `collect` и правила в `brands.yaml`: возможно, слишком строгие исключения |
| `uv: command not found` | Закройте и откройте терминал после установки uv |

## Доступ с другого компьютера

По умолчанию интерфейс доступен только с вашего компьютера. Чтобы открыть коллегам
в локальной сети, задайте пароль в `.env` (`WEB_PASSWORD=...`, логин по умолчанию `admin`) и запустите:

```bash
uv run mr web --host 0.0.0.0
```
